# Patient Intake Automation

## Overview

Automated digital patient intake.

This project is part of a healthcare technology portfolio demonstrating
backend engineering, healthcare automation, AI integration patterns,
API architecture and scalable SaaS development.

## Technology

- Node.js
- Express
- REST API
- Healthcare automation
- AI integration architecture
- Automated testing

## Architecture

```
Client
   |
   v
REST API
   |
   +---- Healthcare Service
   |
   +---- AI / Automation Layer
   |
   +---- Data Layer
```
